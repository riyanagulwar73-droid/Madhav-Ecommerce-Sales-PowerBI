# Madhav Ecommerce Sales - Power BI Dashboard

## 📊 Project Overview
Analyzed Ecommerce sales data for Madhav Store (family business) to identify revenue drivers, customer trends, and product performance. Created interactive Power BI dashboard.

## 🛠️ Tools Used
- Power BI: DAX, Power Query, Visualizations
- Excel: Data Cleaning
- Skills: Business Intelligence, KPI Dashboard, Storytelling

## 📈 KPIs Tracked
- Total Revenue, Orders, Average Order Value
- Sales by Category & Payment Method
- Monthly Revenue Trend & Customer Retention

## 🔍 Key Insights
- Identified top 3 categories driving 80% of Madhav Store revenue
- Found COD vs Prepaid payment pattern
- Suggested inventory optimization based on slow-moving products
